# GRADE_STATISTIC_CALCULATER_PYTHON

# Grade Statistics Calculator

A simple Python program that calculates statistics for a class of students based on their grades.

## Features
- Enter grades for any number of students
- Calculates:
  - Average grade
  - Highest grade
  - Lowest grade
  - Number and percentage of students who passed
  - Number and percentage of students who failed
- Displays a clean, formatted statistics report

## Example Output
```
=== Grade Statistics Calculator ===

===================================
       statistic report  
===================================
 total students : 8
 average grade : 65.12
 highest grade :96.0
 lowest grade  :55.0
 Passed:   6 (75.0%)
 Failed:   2 (25.0%)
===================================
```

## How to Run

1. Clone or download this repository
2. Run the script in Python or open it in Jupyter Notebook
3. Enter the number of students, then enter each grade when prompted

```bash
git clone <your-repo-url>
cd <your-repo-folder>
jupyter notebook GRADE_STATISTIC_CALCULATER.ipynb
```

## Requirements
- Python 3 (no external libraries required)

## Notes
- A grade above 60 is counted as a pass.
